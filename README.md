# Student-Dashboard-
🎓 StudentHub – Student Dashboard
A single-page student dashboard built with plain HTML, CSS and JavaScript. No frameworks, no build step, no dependencies.

Owner: T S Harshini · B.Tech CSE (AI & ML), Mohan Babu University (2023–2027)

Features
Overview stats: courses, average attendance, pending tasks, certifications
My Courses: progress bars per course
Assignments: tick a task to move it to Completed, untick to move it back
Attendance by Subject: per-subject bars with the overall average calculated automatically
My Profile: education, experience, roles and contact links
Responsive layout for phone and desktop
Light and dark mode that follows the system setting
